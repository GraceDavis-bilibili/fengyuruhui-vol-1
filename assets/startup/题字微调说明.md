# 手动微调启动页题字

题字竖排在画面左侧竹林前（暂用游戏自带的黄草字体）：右边一列是“风雨如晦（上）”，左边一列是“既见君子 云胡不喜”。

打开游戏扩展中的 `assets/startup/caption.css`，修改参数并保存，然后重启游戏查看效果。

实际文件位置：游戏目录下的 `extension\风雨如晦（上）\assets\startup\caption.css`。

## 常用参数

| 要改什么 | 第一列（右）：风雨如晦（上） | 第二列（左）：既见君子 云胡不喜 |
| --- | --- | --- |
| 字体 | `--fy-title-font` | `--fy-poem-font` |
| 字号 | `--fy-title-size` | `--fy-poem-size` |
| 左右偏移 | `--fy-title-x` | `--fy-poem-x` |
| 上下偏移 | `--fy-title-y` | `--fy-poem-y` |
| 字间距 | `--fy-title-spacing` | `--fy-poem-spacing` |
| 颜色 | `--fy-title-color` | `--fy-poem-color` |

偏移用 px，正值向右／向下，负值向左／向上。`--fy-caption-top` 改整组题字距顶部的位置，`--fy-caption-left` 改距左边的位置，`--fy-line-gap` 改两列之间的空隙。偏移相对默认排版位置生效；第一列字号变化时第二列会按排版自然左移，可再单独微调。

例如，把第一列换成新魏、字号 36 像素、向右移 10 像素、向上移 4 像素，就把文件中对应参数改为：

```css
--fy-title-font: "xinwei", serif;
--fy-title-size: 36px;
--fy-title-x: 10px;
--fy-title-y: -4px;
```

系统楷体可用 `"KaiTi"`，游戏新魏可用 `"xinwei"`；其他字体需要系统已安装或游戏已声明并加载。字体未找到时会使用后面的备用字体。原来的 clamp 写法用于随窗口缩放，若想固定字号直接写 px 即可。

保留分号、单位和引号。未看到变化时确认改的是游戏扩展里的文件，而不是本任务中的备份或压缩包副本。CSS 内单条参数写错时浏览器可能忽略它，改正后重启即可。

低矮横屏默认隐藏题字以免挡住模式按钮，建议先在桌面窗口微调。以后游戏重启也会自动读这份样式。

本次另已删除设置弹窗里的“风雨如晦启动页／已开启”整行，以及“关闭此启动页后恢复之前的样式。”说明。其他样式选择、模式尺寸和原有总开关入口继续保留。
