# 《风雨如晦（上）》

**作者 / 游戏设计 / 主创：玄蝶**

《风雨如晦》（上）是玄蝶创作的武将设计作品。本项目将其当前发布版本实现为《无名杀》扩展。

当前开发版收录 **38 / 39** 名武将；**庄周**仍作为最后的彩蛋武将单独开发，完成后再补入最终 39 / 39 版本。

- 壁纸与界面美术：ChatGPT
- 测试、修复与操作体验打磨：Grace_Davis
- 代码贡献：清风、蝶设堂、无名杀团队

本扩展以《无名杀》v1.11.5.2为运行环境。

部分游戏本体已经存在的武将及技能实现，使用或参考了《无名杀》本体中的现有代码，并根据玄蝶在《风雨如晦》（上）里发布的版本规则进行删减、覆盖或定点修改。当前完整包中这类既有武将包括：

- 张芝
- 彭羕
- 孟达

- 张华
